# smbldap-tools RPM for EL10

This repository provides RPM packaging for `smbldap-tools` for Enterprise Linux 10 / AlmaLinux 10.

This package was created by using the EPEL 9 package as a base and rebuilding/adapting it for EL10.

## Requirements

Before installing this package, please install `perl-Crypt-SmbHash-el10-rpm` first.

## Notes

This package was built with `mock`.

Build logs and SRPM are included to make the build process reviewable and reproducible.

This is an unofficial package and is provided free of charge. Please use it at your own risk.
